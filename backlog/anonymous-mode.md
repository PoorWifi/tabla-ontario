# Board: feedback box (anonymous-mode)

People want to say things about the session in more than one word - some
with their name on it, some not.

**Your spec must answer:**

- What does "anonymous" mean here technically, given every request
  carries a caller id? What are you promising, and what can you NOT
  promise?
- Free text renders on a very public screen. What is your escaping story,
  and what is its test?
- How much text is too much, and what does the card do when there are
  fifty comments?

**Boundaries:** one directory under `features/`, spec in your README
before code, `npm run gate` green, one commit.
